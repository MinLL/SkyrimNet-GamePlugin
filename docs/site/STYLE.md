# Writing the docs

Who reads these: a player setting SkyrimNet up or getting more out of it, or
a modder building on it. Each page says which in its `audience`.

- **Lead with what the reader can do.** The first sentence of a page or a
  section is the answer, not background.
- **Second person, present tense.** "Turn on the diary", not "the user can
  enable the diary".
- **Say what is true, not when it changed.** "Currently", "new in",
  "recently" and "coming soon" are wrong a release later and fail the check.
  Release notes are where change is described.
- **Embed, do not restate.** Settings, defaults, function signatures and menu
  names come from directives (README.md), never typed by hand.
- **Player pages use player words.** No class names, file paths or config
  keys unless the player has to type them.
- **Short.** Sentences under 25 words, paragraphs of three sentences or
  fewer, a table where items are compared on several things.
- **Video plays on the web but not in the game's overlay.** Never make a
  video the only way to learn something.
