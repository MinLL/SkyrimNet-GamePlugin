# Bio partition tool

> **Historical**: this tool performed the one-time split at the pre-restructure
> layout (`SKSE/Plugins/SkyrimNet/{original_prompts,prompts}/`). Those paths no
> longer exist — run it against a checkout of commit `3700301` or earlier. The
> split's audit trail lives in `report/`; `overrides.csv` remains the record of
> hand attributions.

Splits `original_prompts/characters/` (3,098 bios) into the bios that stay in
`skyrimnet.base` and the per-source-mod `skyrimnet.bios-{mod}` hub packs
(Core `ai_docs/CONTENT_STORE_DESIGN.md`, ruling 26).

```
python partition_bios.py report              # stats + report/ triage files
python partition_bios.py write --out DIR     # DIR/base/prompts/characters, DIR/packs/skyrimnet.bios-*/
```

| File | Purpose |
|---|---|
| `partition_bios.py` | the tool; attribution rules are in its docstring |
| `overrides.csv` | hand attributions that beat the CSV rule (`bioKey,target,note`; target = `base` or plugin file names joined by ` \| `) |
| `mod-titles.csv` | optional `pluginFile,slug,title` display names for packs (defaults derive from the ESP name) |
| `report/` | regenerated by `report`: `packs.csv`, `assignment.csv` (the audit trail), `unattributed.txt` and `multi-claim.csv` (triage) |

Attribution comes from `prompts/translation/{unique,generic}/*.csv` — the
only place a bio is tied to its plugin. Bios with no CSV row default to base
and are listed in `report/unattributed.txt`; resolve them by adding a row to
`overrides.csv`.

Translation CSVs stay in base (hub packs carry only `prompts/characters/*.prompt`).

## Open triage

2026-08-19). They ship in base until attributed. Known-good base keeps among
them: the vanilla guard/encounter generics (`imperial_guard`, `stormcloak_guard`,
`riften_city_guard`, `redoran_guard_5BD`, `nahagliiv_BB0`, `pelagius_bodyguard`,
`female_peddler`, `traveling_noblewoman`, `taunting_adventurer`) and the
`*_requested_removed_by_author` placeholders. The rest are mod followers whose
source plugin is not recorded anywhere in the repo — add a row to
`overrides.csv` when identified. `Project AHO.esm` in `overrides.csv` is the
assumed filename and still needs confirming.
